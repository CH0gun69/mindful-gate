# Icons

Real brand-logo SVGs from [Simple Icons](https://simpleicons.org/) (simple-icons npm
package), copied in as static files — no npm/node dependency in this project.

The icon designs themselves are [CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/)
(public domain; the `simple-icons` package's own code/tooling is MIT, but the SVGs are
CC0), so no attribution is legally required. Kept this note for provenance anyway.

Each brand name/mark is a trademark of its respective owner — used here purely to mock
a real phone's app icons for this hackathon demo, not to imply any affiliation.

Used by `core/mock_data.icon_path_for()` / `ui/widgets/app_icon.py`. "Messages" has no
entry here on purpose — it's a fictional app in this demo, so it keeps its emoji avatar
instead of being forced onto a mismatched real logo.
